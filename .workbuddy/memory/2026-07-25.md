## QFluentWidgets ComboBox tooltip 陷阱

**现象**：
- `combo.setItemData(0, "...", Qt.ToolTipRole)` 报 `takes 3 positional arguments but 4 were given`
- `combo.model()` 报 `'ComboBox' object has no attribute 'model'`

**原因**：
QFluentWidgets 的 `ComboBox` 包装了原生 QComboBox：
- `setItemData(index, value)` 只支持 userData（无 role 参数）
- `model()` 没暴露出来
- 下拉菜单是自己的 `ComboBoxMenu`，不是默认 QListView，不支持逐项 ToolTipRole

**正确做法**：
```python
combo.setToolTip("整段说明文字\n• 选项 A：...\n• 选项 B：...")
```
鼠标悬浮 ComboBox 即显示。逐项 tooltip 在 QFluentWidgets 里做不到。

## QWidget + QSS background 不渲染

**现象**：
- 自定义 QWidget 子类，用 `setStyleSheet("background:#FFF; ...")` 期望有背景色
- 实际看不见，widget 完全透明
- 但 mouse event、tooltip、cursor 都正常

**原因**：
QWidget 默认不渲染 QSS 的 `background` 属性。只有：
- QFrame（及其子类）
- QPushButton、QLabel、QLineEdit 等内置控件
- 显式 `setAttribute(Qt.WA_StyledBackground, True)` 的 QWidget

才支持 QSS 背景。

**症状示例**（BDS Manager v3.03.00 settings.py ColorSwatch）：
- 8 个色块全部看不见，但点击/悬浮/tooltip 正常
- 之前为什么没人发现：某些用户用深色主题 + 选过色块触发过 `_set_theme_color` → 主色变了但没看到自己点了哪个色块

**正确做法**（任选一）：
1. `widget.setAttribute(Qt.WA_StyledBackground, True)` ← 一行解决
2. 改继承 QFrame（天然支持）
3. 在 paintEvent 里手动 `QPainter.fillRect(self.rect(), QColor("#FFF"))`

## BDS 命令：Java → 基岩版修正

**原因**：BDS 不支持 Java 命令 `save-all` / `save-on` / `save-off`，会报 `Unknown command`。

| Java 版 | 基岩版 BDS |
|---------|-----------|
| `save-all` | `save hold`（暂停存档） |
| `save-on` | `save resume`（恢复存档） |
| `save-off` | 无等价（BDS 不需要） |

**优雅停服流程**：
```
save hold → 0.5s → save resume → stop → 等 N 秒 → terminate → 1s → kill
```

**改动文件**（5 个）：
- `backend/server.py` — `send_save_all()` + `stop_server()`
- `pages/console.py` — 预设按钮 + 自动补全（新增 20+ 基岩版命令）
- `main.py` — 快捷键提示文字
- `pages/command_palette.py` — 命令面板
- `pages/settings.py` — 优雅停服标签
